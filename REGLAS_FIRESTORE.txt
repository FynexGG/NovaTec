Reglas de seguridad de Firestore para NOVATEC
=============================================
Dónde pegarlas: consola de Firebase > Firestore Database > pestaña "Reglas".
Borra lo que haya, pega todo lo de abajo y pulsa "Publicar".
Hazlo antes de que venza el "modo de prueba" (30 días).

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Solo se permite el documento de datos de NOVATEC; todo lo demás queda bloqueado.
    match /novatec/cealka {
      allow read: if true;
      allow write: if request.resource.data.keys().hasOnly(['datos', 'actualizado', 'cliente'])
                   && request.resource.data.datos is string
                   && request.resource.data.datos.size() < 900000;
    }
  }
}
