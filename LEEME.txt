NOVATEC – estructura del proyecto
=================================

NOVATEC/
├── index.html            -> Página principal (solo la estructura HTML)
├── LEEME.txt
└── assets/
    ├── css/
    │   └── styles.css    -> Todos los estilos (colores, diseño, botones, tablas)
    ├── js/
    │   ├── firebase.js   -> Conexión con la nube (Firebase Cloud Firestore):
    │   │                    sincroniza los datos entre PC, celular y otros equipos
    │   ├── data.js       -> Datos maestros: insumos, recetas, stock preventivo,
    │   │                    categorías, unidades y pestañas
    │   └── app.js        -> Lógica: login, programación, MRP, ajustes,
    │                        exportación a Excel, historial y configuración
    └── img/
        ├── favicon.svg   -> Ícono de la pestaña del navegador
        ├── chef.jpg      -> Fondo de la pantalla de inicio de sesión  (COPIAR AQUÍ)
        ├── admin.png     -> Imagen del rol Administrador              (COPIAR AQUÍ)
        ├── nutri.png     -> Imagen del rol Nutricionista              (COPIAR AQUÍ)
        └── compra.png    -> Imagen del rol Comprador                  (COPIAR AQUÍ)

Cómo abrirlo: doble clic en index.html (o abrir la carpeta con Live Server en VS Code).
Importante: data.js debe cargarse ANTES que app.js (ya está así en index.html).
Requiere internet para la librería de Excel (SheetJS) y para sincronizar con Firebase.
Sincronización: funciona desde el link publicado (GitHub Pages). Si abres index.html
con doble clic, el sistema funciona pero solo guarda en ese equipo.
Reglas de seguridad: ver REGLAS_FIRESTORE.txt.
